# Contributing

Branches: `main` (production), `develop` (integration), `feature/*`, `fix/*`, `hotfix/*`.
Open a pull request into `develop`; release by merging `develop` into `main`.

Before opening a PR, run the checks listed in the README. PRs must pass CI, explain the change,
list affected features, include testing notes and screenshots for UI changes.

Never commit secrets, real customer data or `.env` files. Use descriptive commit messages.
